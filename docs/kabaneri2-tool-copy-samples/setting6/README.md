# カバネリ設定6 推測ツールのコピーデータ

推測ツールの「データをテキストでコピー」で出した文面を保存している。

## 対応するマイスロデータ（../../kabaneri2-myslot-samples/setting6）

| コピーデータ | 対応するマイスロ | 根拠 |
|---|---|---|
| 01 | 02.txt（9770G） | ボイス・キャラ紹介・アイテムくじ等の途中回数と最終回数の比べ合わせで 02 が大きく有利。もう一方の候補 06（10365G）は約3か月前のデータで、利用者も 02 と確認 |
| 02 | 03.txt（9560G） | CZ履歴の無名10件・生駒11件が 03 の突入回数と一致 |
| 03 | 01.txt（10643G） | 総ゲーム数と入力欄のマイスロが同一 |

## 01・02 は G数とマイスロを直して再計算したもの

もとの 01・02 は、虹トロフィーが出たあたりで「現在G数」の入力を止め、下段ベルだけはその後も数え続けていた。
マイスロ入力欄にも途中時点（01 は2689G、02 は2039G）のマイスロしか貼られていなかった。

そのため、推測ツールに同じ入力（pt・ボタン回数・CZ当選履歴・下段ベル・周期当選）を再現したうえで、次の3点だけを直して再計算し、コピーし直した。

- 現在G数を、対応するマイスロの総ゲーム数（01 は9770、02 は9560）に変更
- マイスロ入力欄を、対応するマイスロの最終データに差し替え
- サミートロフィーを推測に使用を OFF に変更（最終マイスロに虹トロフィーがあり、ON だと設定6確定になるため。03 と同じ扱い）

コピー日時は再計算した時刻、保存データ名はもとのコピーの番号のまま。直す前の文面は git の履歴（コミット 3288767・495d2d8）に残っている。
