# カバネリ設定6 推測ツールのコピーデータ

推測ツールの「データをテキストでコピー」で出した文面を、貼り付けられたまま保存している。

## 注意: 01・02 の G数は途中で止めてある

01 と 02 は、虹トロフィーが出たあたりで「現在G数」の入力を止め、下段ベルだけはその後も数え続けている。
そのため G数が実際より少なく、下段ベル確率（1/50.44、1/80.25）や期待値・期待時給は実際より高く出ている。
03 は G数も最後まで入力してあり、マイスロの総ゲーム数と一致する。

## 対応するマイスロデータ（../../kabaneri2-myslot-samples/setting6）

| コピーデータ | 対応するマイスロ | 確からしさ | 根拠 |
|---|---|---|---|
| 01 | 02.txt（9770G）が有力、06.txt（10365G）も否定できない | 推定 | 入力欄のマイスロ（2689G時点）の回数を超えないのは 02・06 のみ。CZ履歴27件（無名14・生駒13）が 02 の無名13＋生駒13＋VS銅藍2＝27件と一致し、06 は計29件 |
| 02 | 03.txt（9560G） | ほぼ確実 | 入力欄のマイスロ（2039G時点）の回数を超えないのは 03・06 のみ。CZ履歴の無名10件・生駒11件が 03 の突入回数と一致 |
| 03 | 01.txt（10643G） | 確実 | 総ゲーム数と入力欄のマイスロが同一 |
